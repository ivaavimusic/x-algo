## Technical Details

An indexed CLI override such as `smoothing_windows.1=256` inserts the string `"256"` into a declared `list[int]`. Boolean and numeric dictionary overrides have the same problem; non-string dictionary keys cannot match the textual CLI path.

Cast indexed list and dictionary values using their declared element types, normalize dictionary keys only for path matching, and report the actual indexed path. Untyped/Any containers retain string overrides.
