## Technical Details

The training evaluator's `average_precision` depends on input order when predictions share a score. For example, a constant predictor over two users can score either 1.0 or 0.5 depending on which label comes first, although the only decision threshold retrieves both users.

Compute precision/recall increments at the end of each distinct score group. This preserves the threshold interpretation of average precision and makes evaluation independent of ordering within ties.

Validation: original focused suite has 3 failures and 2 passes; the fixed suite has 5 passes with no skips. The primary agent independently reran the actual module's tests on Python 3.13.5. Tests use hand-calculated threshold oracles, including an all-equal predictor whose AP must equal the positive fraction.

```bash
PYTHONPATH=bdsm/runtime python -m pytest -q bdsm/tests/test_metrics.py
```

This is an evaluator correctness fix, not a claim that model or feed quality improved. Full GPU training was not run. Prepared with AI assistance and agent review; human and maintainer review remain pending.
