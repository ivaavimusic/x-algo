## Technical Details

gen_recs_artifacts_gen.py --now-ms ... --self-check generates artifacts at the requested clock, then rebuilds the comparison world at the default clock and rejects the valid post IDs.

Pass the same optional now_ms through run_self_check into the PyArrow invariant check. The default argument preserves existing callers.

Validation: `python -m pytest -q phoenix/tests/test_gen_recs_artifacts_clock.py` on Python 3.13.5. The regression produced **1 failed, 1 passed** at the base revision and **2 passed** with this change.

Actual CLI, NumPy artifacts and parquet invariants with a bounded 200-post world. The trainer loader check skips because JAX and the Rust engine are unavailable.
