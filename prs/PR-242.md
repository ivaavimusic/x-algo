## Technical Details

Nullable Arrow integer columns are converted through float64 before being cast back to integer. This rounds valid post/author IDs above 2**53, while nulls become the minimum signed integer instead of the requested zero fill.

Fill nulls in Arrow before NumPy conversion so present integer values stay exact. Missing columns retain their existing fallback.

Validation: both new regressions fail on the original code and pass on the patch. The primary agent independently reran the two focused cases on Python 3.13.5 with real PyArrow, NumPy, and Zstandard; no skips. Coverage includes direct extraction and a real compressed Arrow IPC payload through `arrow_bytes_to_batch`, with exact IDs, null defaults, action masks, and finite continuous features.
