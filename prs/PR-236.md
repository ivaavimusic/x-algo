## Technical Details

Phoenix's `xai-configlib` declares Python >=3.10, but importing it on Python 3.10 or 3.11 raises `ImportError` because `typing.TypeAliasType` was added in Python 3.12. Phoenix's quickstart also advertises Python 3.11+.

Use the already-required `typing_extensions` backport when the standard-library import is unavailable. Preserve native `typing.TypeAliasType` on newer Python versions: the backport and native runtime types are distinct on Python 3.12, so unconditionally importing the backport would break native alias casting.

Validation:

- Before the fix, the regression suite fails at module import on Python 3.10.18 and 3.11.15; all four cases pass on Python 3.12.12.
- After the fix, all four cases pass on each of Python 3.10.18, 3.11.15, and 3.12.12. Python 3.10 uses the declared minimum `typing-extensions==4.13.0`; the other environments use 4.16.0.
- Cases cover nested alias casting, CLI override value types and immutability, JSON round trips, and invalid-value rejection.
- An isolated Python 3.12 mutation using an unconditional backport import fails all four cases, demonstrating that the tests catch the native-alias regression.
- The new test file passes Ruff checks and formatting. Source lint has the same 21 existing findings before and after the patch, with no new finding signatures; `git diff --check` passes.

Run from the repository root in an environment with this package's declared `typing-extensions` dependency and `pytest` installed:

```bash
PYTHONPATH=phoenix/python/common/xai-configlib/src python -m pytest -q phoenix/python/common/xai-configlib/tests
```

Validation is limited to the configuration library. Full Phoenix GPU training and serving were not run.
