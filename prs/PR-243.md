## Technical Details

Once the per-post image budget is reached, `_render_single_post` stops iterating cards entirely. That removes card titles, descriptions, and poll-choice text even though the limit applies to images. A zero image budget drops every card's text.

Continue processing cards and let `_process_cardv2` enforce its existing image limit. This preserves textual metadata while keeping image count and image placeholders bounded.

Validation: original code has four failing regression cases and one passing control; patched code has five passes. The primary agent independently reran the focused tests on Python 3.13.5. Cases cover zero/limited/unlimited budgets, legacy/unified/poll cards, quote nesting, exact image order, and placeholder count. The shipped renderer self-check also passes.

```bash
python -m pytest -q phoenix/tests/test_mm_encoder_cards.py
```

This verifies rendering semantics, not embedding/recommendation quality or live feed behavior. Prepared with AI assistance and agent review; human and maintainer review remain pending.
