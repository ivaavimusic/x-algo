## Technical Details

A short visit that ends with an explicit "I'm inspired; I'm done" signal needs a different meaning from ordinary closure or inactivity. This adds optional explicit-outcome utility to the shared value model, motivated by [Vible's exit action](https://www.holyvible.com/) and [Empowerverse's growth-oriented recommendations](https://www.empowerverse.org/).

`compute_value_scores_with_user_value` accepts aligned calibrated probabilities of worth-my-time, helped-my-chosen-goal, inspired-exit, and regretted-time outcomes. Nonnegative weights reward the first three and penalize regret; a symmetric cap bounds the adjustment in raw weighted-score units. The existing offset, exploration, cold-start, author-diversity and out-of-network paths are reused. Existing entry points are unchanged; the zero-cap default and missing predictions preserve baseline scores.

The API rejects misaligned slices, invalid probabilities/weights, and non-finite adjusted scores. It accepts fresh or baseline cached weighted scores, and documents the need to prevent repeated adjustment or reuse across weight/model versions. It does not modify visibility filters or replace explicit negative-feedback contributions.

The current Phoenix/protobuf schema has no such heads. This PR supplies a tested scoring primitive and an integration contract, not trained predictions, telemetry collection, or an enabled production feature. The document explains explicit impression-attributed labels, voluntary goals/feedback, cache/transport consistency, calibration and outcome evaluation. Ordinary exits are not treated as positive feedback, and synthetic arithmetic is not evidence of well-being improvement.

Validation:
- Eight tests pass in a public-source Cargo harness importing the actual scoring modules, including the existing hand-computed scoring parity test.
- Covers no-op parity in both multiplier paths, cached/cold-start inputs, explicit successful short visits, regret penalties, caps, cached/fresh equivalence, diversity/OON preservation, alignment, invalid inputs, and overflow.
- `cargo test --locked --manifest-path xai-value-model/tests/user-value/Cargo.toml`
- Rust formatting and `git diff --check`.

The harness excludes the unpublished protobuf adapter; full Home Mixer/model integration remains unverified. This PR is independent of #227 and the companion finite-session proposal.
