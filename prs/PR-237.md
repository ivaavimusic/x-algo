## Technical Details

`Config.from_dict(config.to_dict(), ensure_class=type(config))` rejects the module-qualified class tag written by its own serializer because the required type is reduced to a bare name. Tagless restoration can also select a different registered class with the same name.

Resolve a typed requirement through its qualified registry key and compare the registered class identity. Legacy string requirements keep their existing behavior; ambiguous legacy tags cannot impersonate a different required type.
