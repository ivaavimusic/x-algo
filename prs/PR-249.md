## Technical Details

The task-head training CLI supports a linear head (the default), arbitrary hidden widths, and the shipped `512,256` MLP. `save_checkpoint` writes linear parameters as `abuse_v3/head/w` and `b`, while the runtime loader only accepts the six keys of a two-hidden-layer MLP. Consequently, the default training checkpoint cannot be loaded for scoring, and a one-hidden-layer checkpoint is rejected too.

Normalize the legacy linear names to `w0`/`b0` and require contiguous weight/bias pairs for the actual number of layers. The shipped MLP format continues to load, and incomplete pairs still fail explicitly.

Validation: two actual checkpoint roundtrips fail before the change; eleven tests pass after it with CPU JAX and no skips. Tests initialize each supported head shape, save with the real training writer, load with the real runtime loader, and compare logits. No production model, GPU or internal services were used.

Prepared with AI assistance; the patch and regression results were independently reviewed before submission.
