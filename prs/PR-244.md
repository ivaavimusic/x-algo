## Technical Details

Applying `missing_mask` in `write_sid_snapshot` can modify the caller's supplied int64 code array in place. Reusing that array for an unmasked snapshot then writes stale missing sentinels, and a read-only input array raises instead of being written.

Copy the code array only when applying a missing mask. Output still contains the sentinel at masked rows, while the caller's data remains unchanged.

Validation: all three new tests fail against the original code and pass after the fix. The primary agent independently reran them on Python 3.13.5 with actual NumPy/PyArrow. Tests read real Parquet outputs and cover writable inputs, read-only inputs, and reuse for a subsequent unmasked snapshot.

```bash
python -m pytest -q phoenix/tests/test_sid_snapshot_inputs.py
```
