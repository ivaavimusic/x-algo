## Technical Details

Viewer choice currently has no library-level way to reduce positive attention rewards without also editing the rest of the value-model objective. This adds an opt-in `ValueModelWeights::with_attention_reward_scale(0..=1)` API: at zero, longer viewing cannot contribute a positive reward through the covered attention channels; at one, the original finite configuration is preserved.

The control covers dwell probability, VQV/quoted VQV, continuous dwell and click dwell, video/user video continuation, profile-visit seconds, and the mutual-follow dwell boost. It preserves non-positive weights, all explicit negative-feedback weights, non-attention actions, and diversity configuration. Invalid scales and non-finite attention weights return a typed error.

Motivation: [Vible](https://www.holyvible.com/) and [Empowerverse](https://www.empowerverse.org/) describe recommendations that support intentional use and personal growth. This translates that vision into a narrowly scoped viewer-choice primitive; it makes no claim that adjusting weights establishes improved well-being.

This is a library API, with current entry points and defaults unchanged. The document identifies the Home Mixer/VMRanker propagation and cache invalidation required before enabling a viewer setting. The control must be applied once to fresh weights; it is not a production rollout.

Validation:
- A public-source Cargo harness compiles the actual attention, input, weights, and scoring modules with public dependencies, excluding the unpublished protobuf adapter.
- Tests cover identity, zero/fractional scaling, every attention channel, unchanged negative feedback/weights, invalid inputs, and a hand-computed ordering reversal.
- `cargo test --locked --manifest-path xai-value-model/tests/attention-rewards/Cargo.toml`
- Rust formatting and `git diff --check`.

The full Home Mixer/protobuf build is not validated by the standalone harness. This PR is independent of the companion explicit-outcome and finite-session proposals.
