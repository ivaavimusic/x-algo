## Technical Details

`load_cached` filters each Parquet shard to finite CLS activations with strong labels, but it unconditionally stacks the surviving labels. A shard whose rows are all weak or non-finite therefore raises before subsequent valid shards can load. An empty shard also fails during reshape.

Skip empty and fully filtered shards, retaining eligible users from the remaining files. A split with no eligible users now reports a contextual error rather than failing inside `stack` or `reshape`.

Validation: four regression cases fail on the base revision; all eleven tests in `test_cached_shards.py` and `test_train_head.py` pass with real Parquet files and CPU JAX. The tests cover weak-only, non-finite-only and empty leading shards, an entirely filtered split, and existing head-training checks. No GPU, internal services, model weights or production data were used.

Prepared with AI assistance; the patch and regression results were independently reviewed before submission.
