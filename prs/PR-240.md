## Technical Details

`cast_type(tuple[str, ...], "click,follow,share")` rejects valid values because it treats the variadic tuple annotation as a fixed two-element tuple, and can attempt to cast through `Ellipsis`.

Recognize variadic tuple annotations and cast every supplied value to the declared element type. Preserve empty-tuple handling, heterogeneous fixed tuples, and fixed-tuple length validation.
