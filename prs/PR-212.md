## Technical Details

Fixes #202

Author diversity currently resets on every For You request. This change seeds the existing diversity count with bounded, time-decayed author exposures from served history, so recent deliveries influence subsequent requests.

The feature is off by default and reuses the existing history reader and writer. It preserves legacy scoring when disabled, history is unavailable, settings are invalid, or history exceeds the input budget. Both scoring paths use the same calculation:

```text
history[a] = weight * min(max_count, sum(2 ** (-age_ms / half_life_ms)))
exponent = current_pool_count[a] + history[a]
multiplier = floor + (1 - floor) * decay ** exponent
```

When enabled, history and current candidates use the original author's ID for reposts. Replayed batches and conversation entries sharing a feed position are deduplicated; invalid or expired entries are skipped. Counts reflect served items, not confirmed views.

### Configuration

The feature applies only to For You and requires `EnableAuthorDiversity` and the served-history path (`EnableUrtMigrationComponents`).

| Parameter | Default | Meaning |
|---|---:|---|
| EnableCrossRequestAuthorDiversity | false | Enable the feature |
| AuthorDiversityHistoryWindowSeconds | 300 | Recent-history window |
| AuthorDiversityHistoryHalfLifeSeconds | 60 | Exposure half-life |
| AuthorDiversityHistoryWeight | 0.25 | Historical count weight; 0 disables treatment |
| AuthorDiversityHistoryMaxCount | 5 | Per-author cap before weighting |
| AuthorDiversityHistoryMaxItems | 200 | Maximum recent distinct exposures |

`tools/author-diversity-tests/treatment.json` provides an example override. These defaults still need evaluation on real traffic.

### Validation

- All 37 local contract and regression tests pass, using production functions with explicit service adapters.
- Disconnecting history causes the cross-request regression to fail as expected.
- Coverage includes both scoring paths, delayed writes, failure recovery, 90 read/write schedules, eight synchronized threads, and 1,000 randomized property trials.

Run from the repository root with Python 3.9+ and Rust 1.90+ on PATH:

```sh
python3 tools/author-diversity-tests/run.py --mutation-check
```

The test README describes the harness and storage assumptions.

### Limitations

- The public repository lacks the complete service dependencies; a full internal build and CI validation are still required.
