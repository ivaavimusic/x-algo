## Technical Details

Manual discovery searches the entire absolute path for the run-id and sample-count regexes. It reports a leading directory such as private or Users as the run ID, can use an unrelated ancestor sample count, and returns before scanning a requested elapsed_samples directory.

Recognize the sample directory by its name; for an explicit run directory, parse the run ID from its name and sample count from its parent. Sample-directory requests now reach the existing completed-child selection.

Validation: `python -m pytest -q phoenix/tests/test_manual_checkpoint_paths.py` on Python 3.13.5. The regression produced **3 failed, 2 passed** at the base revision and **5 passed** with this change.

Actual FileSystemProvider with synthetic filesystem completion metadata, committed-directory markers and unfinished-directory exclusion. Does not deserialize tensor payloads or run checkpoint restore.
