## Technical Details

`from_dict(..., ignore_unregistered_cls=True)` still raises when an unknown config class is nested inside an ordinary dictionary, including a dictionary field of a registered config.

Propagate the existing opt-in unknown-class policy through dictionary recursion. Unknown classes become `None` as they already do in list/tuple recursion; strict mode and known configs retain their behavior.
